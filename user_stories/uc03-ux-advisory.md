## 📋 BACKGROUND INFORMATION

## Use Case Overview
**UC3 — UX Advisory** transforms manual UX reviews into AI-powered, data-driven analysis that integrates external knowledge sources for comprehensive quality assessment.

### Key Value Propositions
- **External Data Integration**: Corporate style guides, WCAG standards, industry best practices
- **Multi-Level Analysis**: Visual → Page → Dashboard hierarchy
- **Actionable Recommendations**: Specific fixes with auto-implementation options
- **Measurable UX Scores**: Quantified improvement tracking across categories

### Chat Demonstration Scenario
```
Builder Request: "Review Visual01 UX using our corporate style guide and accessibility standards"

AI Response Features:
✓ External Knowledge Loading (**dm Standards für Berichtsdesign** v2.4, WCAG 2.1, Best Practices)
✓ Comprehensive UX Scorecard (74/100 overall with category breakdown)
✓ Priority-Ranked Fix Recommendations (High/Medium/Low with source citations)
✓ Multi-Level Analysis Options (Visual/Page/Dashboard contexts)
✓ Custom System Prompts (Industry focus, compliance level, user expertise)
```

### Business Benefits for Strategy One Integration
- **Quality Assurance**: Automated UX compliance checking reduces manual review time
- **Knowledge Integration**: Leverages existing **dm Standards für Berichtsdesign** and external best practices
- **Scalable Excellence**: Consistent UX standards across all dashboard creations
- **Risk Mitigation**: Accessibility compliance built into the creation workflow

### Technical Innovation Highlights
- **External Data Sources**: Real-time integration with style guides and standards
- **Contextual Analysis**: Multi-level review scope (Visual/Page/Dashboard)
- **Custom Prompting**: Industry-specific and role-based review criteria
- **Auto-Fix Capabilities**: One-click implementation of recommended improvements
