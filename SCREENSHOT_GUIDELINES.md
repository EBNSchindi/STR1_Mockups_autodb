# Screenshot Guidelines

Consistent, presentation‑ready screenshots for all mockups (PowerPoint/Canva).

## Viewport & Zoom
- Resolution: 1440 × 900 (or 1280 × 800 if needed)
- Browser zoom: 100%
- OS scale/DPI: 100% (no scaling)

## Browser Setup
- Disable bookmarks bar and extensions UI
- Use light OS window chrome where possible
- Hide scrollbars if possible (ensure full component is visible)

## Margins & Cropping
- Outer margin: 16–24px transparent/white padding around content
- Crop to the component/scene of interest (avoid full‑screen if not needed)
- Keep headers/toolbars fully visible when relevant

## Theme & Language
- Language: English (per project scope)
- Theme: default as shown in mockups (bright unless the UC demonstrates dark)
- Badge: "AUTO DASHBOARD" visible in chat headers where applicable

## Composition
- Include the user message + bot card + suggestions for chat scenes
- For editor layout, show left rail + center editor + assistant panel
- Keep at least one call‑to‑action (e.g., Send, Apply) visible

## File Naming
- Format: `UC##_short-title_[light|dark]_v01.png`
- Examples: `UC01_guided-settings_light_v01.png`, `UC10_setup-wizard_light_v01.png`

## Export Settings
- Format: PNG (preferred) or high‑quality JPG
- Scale: 1x (no upscaling); use 2x only if fonts appear blurry
- Color profile: sRGB

## Accessibility & Readability
- Minimum font size in capture ≥ 12px equivalent
- Ensure color contrast remains readable post‑export

## Do/Don’t
- Do align content to a clean grid; avoid accidental scroll offsets
- Don’t include OS notifications or unrelated tabs/toolbars
- Don’t crop off interactive affordances (icons, buttons) midway

## Checklist Before Export
- [ ] English labels and timestamps
- [ ] Consistent badge and toolbar icons
- [ ] Correct viewport and zoom
- [ ] Clean margins, no clipped elements
- [ ] Filename follows convention
